InstaLearn — Better Than Good Edition

This build focuses on making the student experience feel like a real tutoring platform instead of a simple quiz site.

Major improvements:
- Premium subject library with search and filters.
- Subject cards now show category, topic count, difficulty levels, mastery, and next topic.
- Subject detail now has curriculum metrics and a recommended next step.
- Topic list is interactive and shows completed / in-progress / ready states based on subject mastery.
- Existing Firebase authentication, Gmail verification gate, password reset/change, password reminder, dashboard, lessons, quizzes, progress, settings, and website-focused assistant are preserved.
- Assistant remains focused on InstaLearn website help rather than general AI questions.

Important:
- This is still a front-end prototype using Firebase Authentication plus browser/local storage for student progress/profile data.
- Tutor booking, payments, and full admin management are not pretending to be live systems yet.
